# CHILLVIBE ❄️ — Sub-Zero Cold Drink Refreshment Website

Welcome to **CHILLVIBE**, an ultra-modern, fully responsive, glassmorphic web application built for cold drink lovers and modern mixology enthusiasts. Featuring an vibrant **Orange & Frosted White** aesthetic, script-typography calls-to-action, dynamic drink customizers, an interactive mixology bench, and real-time order tracking.

---

## 🌟 Key Features

### 1. 🍹 100% Chilled Drinks Catalog
- **12 Pre-configured Products:** Across 5 categories (*Carbonated Fizz, Frozen Slushies, Cold Brew Iced Teas, Fruit Citrus Zests, and Sub-Zero Mocktails*).
- **Advanced Filtering & Search:** Instant live search autocomplete, category tabs, price range slider ($3–$12), calorie filters, and sorting (Price, Rating, Popularity).

### 2. 🧊 "Ice & Sweetness Lab" (Customizer Modal)
- Select serving size (*Regular, Large, Jumbo*).
- Pick sub-zero ice levels (*0% No Ice, 25% Light Ice, 50% Regular Ice, 100% Sub-Zero Ice*).
- Fine-tune sweetness percentage via interactive range slider ($0\% - 100\%$).
- Add fresh toppings (*Mint Leaves, Lemon Slices, Popping Boba, Chia Seeds*) with real-time price calculation.

### 3. 🧪 Interactive Mixology Bench
- Allows users to build their own signature cold drink step-by-step!
- Select **Liquid Base** + **Fruit Flavor Extract** + **Custom Name** and add directly to the cart.

### 4. 🛍️ Sliding Glass Cart Drawer & Checkout
- Real-time subtotal, discount, and delivery fee calculation.
- **Dynamic Free Delivery Progress Bar** (Unlocks free delivery when orders cross $20).
- Promo code application system (e.g., `CHILL20` for 20% OFF).
- Full express checkout modal with cash on delivery and mobile wallet support.

### 5. 🎯 Extra Engagement Features
- **Chill Mood Picker:** Recommends drinks based on user vibe (*Energy Boost, Heat Wave, Post Workout, Late Night Relax*).
- **Spin & Win Rewards Wheel:** Interactive HTML5 Canvas wheel for instant coupon codes.
- **Live Order Tracker:** Simulated real-time countdown timer with delivery status steps.
- **Frosted Light & Dark Mode:** Toggle between translucent white frosted glass and dark glass themes.

## 🎨 Design System & Visual Highlights

- **Color Palette:** Warm Cream (`#FFF8F0`), Radiant Orange (`#FF6B00`), Sunlight Amber (`#FFA726`), Frosted Glass (`rgba(255, 255, 255, 0.65)`).
- **Typography:** 
  - *Body & Headings:* Plus Jakarta Sans
  - *CTA & Script Highlights:* Pacifico (`font-script`)
- **Glassmorphism:** Enhanced using Tailwind CSS, backdrop blurs (`backdrop-filter: blur(16px)`), subtle translucent borders, and ambient floating glowing orbs.

---

## 🛠️ Tech Stack & Dependencies

This project is built as a single-file, zero-build web architecture for maximum performance and portability:

- **HTML5** & **CSS3**
- **Tailwind CSS** (via CDN)
- **JavaScript (Vanilla ES6)**
- **Google Fonts** (*Pacifico* & *Plus Jakarta Sans*)
- **Lucide Icons** (via CDN)
- **HTML5 Canvas** (for the rewards wheel)

## 🚀 Getting Started

No installation or node modules setup required!

1. Clone or download this repository.
2. Ensure both `index.html` and `README.md` are in the project folder.
3. Open `index.html` in any modern web browser (Google Chrome, Firefox, Safari, Edge).
